# VitalsGuard Agent Rules

- Just before every task completion/packup, you must automatically update all documentation, changelogs, trackers, and version files with the relative content of your changes. Do not wait for the user to explicitly request this.
- Automatically stage, commit, and push all changes to the remote git repository.
- CRITICAL: DO NOT DELETE USER DATA AT ANY COST DIRECTLY FROM THE DATABASE OR LOCAL STORAGE. Always preserve user profiles, logs, and vitals records.
